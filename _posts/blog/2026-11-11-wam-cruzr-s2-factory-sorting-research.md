## 当前场景与条件

**场景与任务：** 工厂流水线分拣。机器人从流水线上拿起一个工件，将工件移到脸前扫码，再根据编码放到对应位置。调研目标是先跑通公开世界模型项目，再评估其对抓取、扫码姿态调整和放置动作的帮助；扫码解码和编码到目标位置的映射先由独立模块完成。

**现有硬件：** 已确认使用优必选 Cruzr S2。机械臂与末端执行器配置、相机类型、SDK 控制权限、状态读取接口和控制频率尚待核实；GPU 型号、数量、显存及外部计算机接入条件也尚未确认。真机适配前需确认能同步获取图像、机器人状态与动作记录，并能发送所需控制指令。

## DreamerV3

**主要框架：** 将图像和本体状态编码为潜在状态，由循环状态空间模型（RSSM）预测动作之后的状态、奖励和终止信号，再用“想象轨迹”训练 Actor-Critic 策略。执行时根据真实观测更新状态并由策略输出动作，标准方法不在每一步搜索候选动作。

**复现难度：** 官方小任务入门中等，完整论文结果较难。适合学习“世界模型如何帮助策略学习”；迁移到 Cruzr S2 仍需定义观测、动作、奖励和环境接口。

**所需条件：** Python 3.11+、JAX 和任务环境，仓库提供 Docker。支持 CPU 调试，正式训练建议使用兼容 JAX 的 GPU，显存与耗时随模型、批量和任务变化。

**复现流程：** 安装依赖 → 选择 Crafter 等官方任务 → 用 debug 配置检查运行链路 → 切回正常配置训练 → 查看奖励曲线与预测结果，并重复评测。debug 跑通不代表策略已学会任务。

[论文（2023 预印本 / 2025 Nature）](https://arxiv.org/abs/2301.04104) · [作者维护的开源重实现与操作说明](https://github.com/danijar/dreamerv3)

## DreamZero

**主要框架：** 基于视频生成模型，在共享网络中联合生成未来视频与机器人动作块。执行后用真实观测刷新上下文，形成“观测 → 视频/动作联合预测 → 执行 → 再观测”的 WAM 闭环。

**复现难度：** 官方推理较高，Cruzr S2 适配更高。官方权重不等于已支持 Cruzr S2，还需采集本体数据、适配观测与动作接口并进行微调。

**所需条件：** 公开的 14B 标准推理路线要求 Python 3.11、PyTorch 2.8+、CUDA 12.9+ 和至少两张 GPU。官方测试平台包括 H100、GB200，具体配置需按官方说明核对，不能假定任意两张消费级显卡都能运行。

**复现流程：** 安装依赖并下载 DreamZero-DROID 权重 → 启动多卡推理服务 → 运行测试客户端，确认动作返回和预测视频输出 → 完成 DROID 仿真闭环评测 → 采集 Cruzr S2 同步数据并适配、微调 → 从单阶段真机测试扩展到完整分拣。初次推理无需先下载训练数据；仿真中的托管 API 路线需申请访问，自建服务需核对客户端协议。

[论文（2026）](https://arxiv.org/abs/2602.15922) · [代码与复现说明](https://github.com/dreamzero0/dreamzero) · [新本体适配指南](https://github.com/dreamzero0/dreamzero/blob/main/docs/DATASET_TO_GEAR_AND_TRAIN.md)

当前选择：以 DreamZero 为机器人 WAM 主线，DreamerV3 用于理解世界模型与强化学习。以上为文献与公开说明整理，尚未在本地或 Cruzr S2 上验证；具体依赖和硬件要求以复现时固定的仓库版本为准。
